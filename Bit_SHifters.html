About

What is
Project Vaulted?

Project Vaulted is our summer passion project — a fully custom AI voice assistant built into a physical enclosure, powered by a Raspberry Pi 5 and the Claude API.

Say "Hey Orbis" and it wakes up, listens, thinks, and speaks back — all running on hardware we assembled ourselves.

How it's built

🧠
Claude API
Powers the intelligence layer — processing speech and generating smart responses.
AI Brain
🖥️
Raspberry Pi 5
The physical computer at the core. Runs Raspberry Pi OS and connects all hardware.
Hardware
🎙️
Porcupine + Whisper
Wake word detection and speech-to-text transcription with high accuracy.
Voice Input
🔊
ElevenLabs TTS
Realistic AI-generated voice output — not a robot, actually sounds like Orbis.
Voice Output
💡
WS2812B LEDs
RGB LEDs in the enclosure — glow green when listening, pulse blue when thinking.
Hardware
🐍
Python
The entire pipeline — wake word → transcription → AI → speech — one Python script.

Roadmap

Build timeline

Weeks 1–2
Setup & Planning
Order hardware, set up GitHub, install Raspberry Pi OS, create Notion build journal.
Active
Weeks 3–5
Core Software Build
Wake word, speech-to-text, Claude API integration. Each team member owns one module.
Upcoming
Weeks 6–7
Full Integration
Connect all modules. Add ElevenLabs voice output and LED logic. Stress test 50+ queries.
Upcoming
Weeks 8–9
Hardware Enclosure
Mount everything inside the custom bobblehead. Manage thermals and cable routing.
Upcoming
Week 10
Polish & Launch
Film demo video, write project page, final Instagram reveal, start college essay drafts.
